# Simple Linear Regression – Marketing ROI Analysis

## Project Overview

This project analyzes the relationship between marketing expenditure and sales using Simple Linear Regression. The objective is to identify the marketing channel with the strongest influence on sales and provide data-driven recommendations for marketing budget allocation.

## Dataset

The dataset contains the following variables:

* TV
* Radio
* Social_Media
* Sales

## Project Objectives

* Load and explore the dataset
* Handle missing values
* Perform exploratory data analysis (EDA)
* Identify the marketing channel most correlated with Sales
* Build an OLS regression model using Statsmodels
* Validate regression assumptions
* Interpret model results
* Provide an ROI-based marketing recommendation

## Softwares Used

* Python
* Pandas
* Matplotlib
* Statsmodels

## Installation

Installed Statsmodels

## Analysis Summary

* Missing values were identified and removed.
* Correlation analysis showed that TV advertising had the strongest relationship with Sales.
* A Simple Linear Regression model was built using TV as the predictor variable.
* The model achieved an R-squared value of approximately 0.999.
* Diagnostic plots confirmed that the assumptions of linearity, normality, and homoscedasticity were satisfied.

## Business Recommendation

TV advertising should receive priority marketing budget allocation because it demonstrated the strongest positive relationship with Sales and produced the highest predictive value among all marketing channels.
